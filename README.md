# হিসাবডেস্ক — HisaabDesk

বাংলাদেশের ব্যবহারকারীদের জন্য তৈরি সম্পূর্ণ অফলাইন, বাংলা-প্রথম ব্যক্তিগত ও পারিবারিক আর্থিক হিসাবের Android অ্যাপ। কোনো সার্ভার, অ্যাকাউন্ট বা ইন্টারনেট ছাড়াই সব ফিচার কাজ করে। সব তথ্য শুধু আপনার ফোনেই থাকে।

- **অ্যাপ:** HisaabDesk (হিসাবডেস্ক) · **সংস্করণ:** 1.0.0 (versionCode 1)
- **প্যাকেজ:** `com.hisaabdesk.app`
- **ডেভেলপার:** Shohan Khan · **ইমেইল:** [helloiamshohan@gmail.com](helloiamshohan@gmail.com)
- **সর্বনিম্ন Android:** 8.0 (API 26) · **Target:** API 34 · **ভাষা:** বাংলা · **মুদ্রা:** বাংলাদেশি টাকা (৳, পয়সা-ভিত্তিক হিসাব)

## বৈশিষ্ট্য

- **ড্যাশবোর্ড** — আসল ডাটাবেস থেকে তরল ব্যালেন্স, সঞ্চয়, পাওনা, দোকানের বাকি, ব্যক্তিগত দেনা, এনজিও/ব্যাংক ঋণ বকেয়া, মোট সম্পদ/দায় ও নিট সম্পদ; আজ/এই মাসের আয়-ব্যয়; দ্রুত কাজ।
- **অ্যাকাউন্ট** — নগদ, ব্যাংক, মোবাইল ব্যাংকিং, সঞ্চয়, অন্যান্য; শুরুর ব্যালেন্স, আর্কাইভ, অনুসন্ধান, ইতিহাস, অ্যাকাউন্ট স্থানান্তর (দুই দিকের এন্ট্রি একসাথে, আয়/ব্যয় নয়)।
- **লেনদেন** — আয়/ব্যয় যোগ, অনুসন্ধান, সংশোধন (মুছে ফেলা), পুনরাবৃত্ত লেনদেন (ম্যানুয়াল পোস্ট বা ঐচ্ছিক অটো-পোস্ট, ডুপ্লিকেট প্রতিরোধসহ)।
- **ক্যাটাগরি** — নিজের তৈরি আয়/ব্যয় ক্যাটাগরি ও সাব-ক্যাটাগরি; ব্যবহৃত ক্যাটাগরি মুছা হয় না, আর্কাইভ হয়।
- **দোকানের বাকি** — দোকান প্রোফাইল, পণ্যভিত্তিক কেনাকাটা (লাইনে: `নাম | পরিমাণ | দাম`), নগদ+বাকি বিভাজন, আংশিক/পূর্ণ পেমেন্ট; পেমেন্টে আবার ব্যয় ধরা হয় না।
- **ব্যক্তিগত ধার-দেনা** — ব্যক্তি প্রোফাইল, ধার নেওয়া/দেওয়া, আংশিক পরিশোধ, মেয়াদ উত্তীর্ণ সতর্কতা; ফেরত পাওয়া মূলধন আয় নয়।
- **এনজিও ঋণ** — চুক্তিভিত্তিক হিসাব; সার্ভিস চার্জ না দিলে মোট পরিশোধযোগ্য "জানা নেই" — অ্যাপ কিছু অনুমান করে না।
- **ব্যাংক ঋণ** — তিনটি স্পষ্ট পদ্ধতি: রিডিউসিং ব্যালেন্স (EMI সূত্র), ফ্ল্যাট সুদ, ম্যানুয়াল কিস্তি তালিকা; কিস্তি তালিকা ও সুদ/আসলের বিভাজন (যেখানে নির্ণয়যোগ্য)।
- **সঞ্চয় ও বাজেট** — সঞ্চয় জমা/উত্তোলন (আয়/ব্যয় নয়), মাসিক বাজেট, ব্যবহারের হার ও অতিক্রম সতর্কতা।
- **রিপোর্ট** — আজ/৭ দিন/মাস/বছর: আয় বনাম ব্যয়, ক্যাটাগরিভিত্তিক ব্যয় (চার্ট), অ্যাকাউন্ট ব্যালেন্স, শেয়ারযোগ্য সারাংশ।
- **নিরাপত্তা** — PBKDF2 পিন লক, ব্যর্থ চেষ্টায় ক্রমবর্ধমান অপেক্ষা, বায়োমেট্রিক-প্রস্তুত সেটিং, অ্যাপ ব্যাকগ্রাউন্ডে গেলে পুনরায় লক।
- **ব্যাকআপ/পুনরুদ্ধার** — JSON ব্যাকআপ (SHA-256 যাচাইসহ), পাসওয়ার্ড-এনক্রিপ্ট করা ব্যাকআপ (PBKDF2 + AES-256-GCM), Storage Access Framework দিয়ে ফাইল নির্বাচন; ব্যর্থ রিস্টোরে বর্তমান ডেটা অপরিবর্তিত।
- **রিমাইন্ডার** — WorkManager ভিত্তিক সাধারণ রিমাইন্ডার; নোটিফিকেশনে টাকার অঙ্ক দেখানো হয় না।

> নতুন ইনস্টলে কোনো নমুনা অ্যাকাউন্ট, ব্যালেন্স বা লেনদেন থাকে না। প্রথম চালুতে পিন তৈরি ও ঐচ্ছিক প্রথম অ্যাকাউন্টের পর শূন্য ড্যাশবোর্ড দেখায়।

## বিল্ড ও টেস্ট

প্রয়োজন: JDK 17, Android Studio (বা Android SDK 34)।

```bash
./gradlew testDebugUnitTest   # ইউনিট টেস্ট
./gradlew lintDebug           # লিন্ট
./gradlew assembleDebug       # ডিবাগ APK -> app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease     # রিলিজ APK -> app/build/outputs/apk/release/ (সাইনিং সিক্রেট ছাড়া unsigned)
```

**ইনস্টল:** APK ফোনে কপি করে খুলুন → অজানা উৎস থেকে ইনস্টলের অনুমতি দিন → Install। GitHub Actions থেকে: Actions ট্যাব → সর্বশেষ *Android CI* রান → Artifacts → `hisaabdesk-debug-apk` ডাউনলোড করুন। রিলিজ থাকলে Releases পেজ থেকেও APK ডাউনলোড করা যাবে।

## GitHub Actions ও রিলিজ

- `.github/workflows/android-ci.yml` — push/PR/manual: JDK 17, ইউনিট টেস্ট, লিন্ট, ডিবাগ APK + SHA-256, আর্টিফ্যাক্ট আপলোড।
- `.github/workflows/release.yml` — `v1.0.0` ফরম্যাটের ট্যাগ পুশ করলে টেস্ট + রিলিজ APK + চেকসামসহ GitHub Release। সাইনিং সিক্রেট (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) সেট থাকলেই সাইন করা হয়; না থাকলে রিলিজটি **unsigned** বলে স্পষ্টভাবে চিহ্নিত থাকে। কিস্টোর কখনো রিপোতে কমিট করবেন না; কিস্টোর হারালে পুরনো অ্যাপের ওপর আপডেট ইনস্টল করা যাবে না।

## পিন ও পুনরুদ্ধার (গুরুত্বপূর্ণ সীমাবদ্ধতা)

পিন শুধু PBKDF2-HMAC-SHA256 হ্যাশ + র‍্যান্ডম সল্ট আকারে থাকে। **কোনো সার্ভার নেই বলে ভুলে যাওয়া পিন দূর থেকে পুনরুদ্ধার করা যায় না।** একমাত্র পথ: আগে নেওয়া ব্যাকআপ নতুন ইনস্টলে রিস্টোর করা। তাই নিয়মিত **এনক্রিপ্ট করা ব্যাকআপ** নিয়ে নিরাপদ জায়গায় রাখুন।

## নিরাপত্তা ও সীমাবদ্ধতা (সৎ বিবরণ)

- এই সংস্করণে ডাটাবেস আলাদা SQLCipher এনক্রিপশনে **নেই**; সুরক্ষা আসে ফোনের নিজস্ব এনক্রিপশন + অ্যাপ পিন থেকে। ব্যাকআপে ঐচ্ছিক AES-256-GCM এনক্রিপশন আছে।
- Instrumented/DB/UI টেস্ট এমুলেটর ছাড়া চালানো যায় না — `docs/TEST_PLAN.md`-এ কোন টেস্ট চালানো হয়েছে/হয়নি তা সৎভাবে নথিভুক্ত আছে।
- ব্যাংক ঋণের সুদ শুধু বেছে নেওয়া পদ্ধতি ও দেওয়া তথ্য অনুযায়ী হিসাব হয়; তথ্য কম থাকলে অ্যাপ অনুমান করে না।
- Android ব্যাটারি সাশ্রয়ে রিমাইন্ডার দেরি হতে পারে।
- রসিদ ছবি সংযুক্তি এই সংস্করণে নেই।
